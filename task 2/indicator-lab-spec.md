## 5. 计算公式标准

### 5.1 RSI (Relative Strength Index)

```
Δprice[i] = close[i] - close[i-1]
gain[i] = max(Δprice[i], 0)
loss[i] = max(-Δprice[i], 0)

avg_gain = SMA(gain, 14)   # 最近 14 根阳线涨幅均值
avg_loss = SMA(loss, 14)   # 最近 14 根阴线跌幅均值

RS  = avg_gain / avg_loss
RSI = 100 - 100 / (1 + RS)
```

> 注: 使用简单 SMA 便于理解教学。

### 5.2 MACD (Moving Average Convergence Divergence)

```
EMA(t, N) = close[t] × (2/(N+1)) + EMA(t-1, N) × (1 - 2/(N+1))

DIF  = EMA(close, 12) - EMA(close, 26)
DEA  = EMA(DIF, 9)
MACD柱 = 2 × (DIF - DEA)    # 乘以 2 放大柱状体，亦称 BAR
```

**金叉**: DIF 从下方上穿 DEA (买入信号)
**死叉**: DIF 从上方下穿 DEA (卖出信号)

### 5.3 Bollinger Bands

```
MA(20)   = SMA(close, 20)
σ(20)    = std(close, 20, ddof=1)          # 样本标准差
上轨      = MA + 2σ
下轨      = MA - 2σ
带宽      = (上轨 - 下轨) / MA              # 相对带宽
%B       = (close - 下轨) / (上轨 - 下轨)   # 价格在带内的位置 (0~1)
```

### 5.4 ATR (Average True Range)

```
TR[i] = max(
    high[i] - low[i],                 # 当日振幅
    |high[i] - close[i-1]|,           # 当天最高 - 昨天收盘
    |low[i] - close[i-1]|             # 昨天收盘 - 当天最低
)

ATR = EMA(TR, 14)
```
